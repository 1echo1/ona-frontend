# ona-frontend

## 🛠️ Built With
- [React Native](https://reactnative.dev/) - Core framework for building native mobile UI
- [Expo](https://expo.dev/) - React Native framework and tooling for building, running, and deploying the app on iOS and Android
- TypeScript - For type safety across the app.
  
<br>

## 🚀 Getting Started
Install dependecies
```bash
npm install
````
<br>

Running the app
```bash
npx expo start
````
